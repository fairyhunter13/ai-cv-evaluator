# Bundle history

## 2026-08-21

- **Update**: the checker pin moves to okf `v0.5.3`, which closes the last unbuilt item of the stamping plan. §5.5 makes staleness a plain date comparison, so `stale_after` says nothing at all until the day it says red, and a passing check that advanced the date would be silencing the calendar rather than answering it. `okf verify` now counts down instead: inside 30 days it prints `warning: stale in N day(s)` and leaves the exit code alone, so a bundle learns about the cliff a month before it falls off rather than on the morning its CI turns red. Nothing else moved — `okfrules check` is byte-identical at this tag.
- **Update**: the checker pin moves to okf `v0.5.2`. Four fleet sources are issue trackers and directory listings whose HTML differs on every request, so the digests recorded at `v0.5.1` never matched twice and the check reported drift forever — noise in the one place the check was meant to be worth having. A digest is now recorded, and a mismatch called drift, only after a second fetch agrees with the first; a source that fails that proves reachability and nothing more, which is all it had ever proved.
- **Verified**: 4 of 10 concepts carry a machine stamp, written by `okf verify -stamp` and not by hand. §5.3 reads the tier off the actor, so `process:okf-verify` is machine-confirmed and stays separable from a human review at a glance. The run settles each `sources[].resource` on its shape — a `commit <sha>` against this history, a path by existence, a URL by fetching it and recording a `digest:` to compare against next time — and stamps only what it proved. A concept with nothing outward to check earns no stamp: rubber-stamping the other 6 would cost the key its meaning.
- **Update**: the checker pin moves to okf `v0.5.1`. It adds `okf verify`, drops `VerifiedWellFormed`'s demand for a `human:` actor — that demand made §5.3's machine tier unreachable, and the anti-forgery guard moved into the writer, which can see `CLAUDECODE` where a document rule cannot — and adds `SourceHasAResource`, which holds §5.1's one required key within a `sources` entry. One pin for the fleet is the point, so this repo moving late would read as drift in `okf sweep` rather than as a repo holding back deliberately.
- **Update**: the checker pin moves to okf `v0.4.1`, where `ActorConvention`, `StatusVocabulary`, `FootnoteLabelsJoinSources` and `AttestedComputationHasContract` are `Standard()` rather than `Strict()` — the fleet conversion they were staged behind finished and all ten bundles measure zero, the same promotion condition `NoIntraBundleWikilinks` met at v0.2.1. One pin for the fleet is the point, so this repo moving late would read as drift in `okf sweep` rather than as a repo holding back deliberately.
- **Update**: the index is the reference shape (§8). Every one of this bundle's 7 directories gets its own `index.md`, headed by the `type` verbatim and singular, entries `* [Title](file.md) - description` sorted case-insensitively by title; the root lists directories and nothing else. It listed all 10 concepts behind one file, which is the disclosure problem §8 exists to solve. The shape is taken from `bundle/index.py` in the cloned reference rather than from §8's prose, because `index.md` is regenerated on every run there and never hand-authored — so the generator is what "ideal" means, down to `[dir](dir/index.md)` where §8 writes `[dir](subdir/)`. `log.md` stays unlisted; the root keeps its `okf_version` and its preamble. The preamble said four of *nine* concepts share a subject; there are ten.
- **Update**: [candidate evaluation](computations/candidate-evaluation.md) gets the rest of its §10 contract. `computation` was `PerformIntegratedEvaluation`, a symbol where §10.3 requires a path, and is now the handler file. `executor.receipt` declares the ten fields a run must return, and [the attester](references/attesters/evaluation_receipt.py) is written against them, so it fails every evaluation today on its first check — the receipt is empty. That was already this concept's thesis; the declaration turns it from a paragraph into a red check. It compares model, prompt version and temperature against the sanctioned ones, refuses a stored score that is not the pre-clamp one, and refuses a derived score outright, because a derived score was never assessed.
- **Update**: the vocabularies the spec closes, measured against the cloned reference bundles rather than against a reading of it — `generated.by` is `claude/opus-5` in 9 concepts, the one spelling of it that is §7's `<producer>/<version>`; 9 date-only `generated.at` values become instants; 4 numeric `[^1]` footnotes are keyed to a `sources[].id` (§5.1), because a position misattributes silently the moment the list is reordered. okf `v0.4.0` is what measures them: its `-strict` arm carries `ActorConvention`, `StatusVocabulary` and `FootnoteLabelsJoinSources`, and this bundle is now zero on all three.
- **Update**: the checker's module path changes and nothing else does. `okfrules` and `okf` merged into one module at okf `v0.3.0` -- the fleet rules are now the package `okf/rules` and the binary is built from `cmd/okfrules` in the okf module -- so `make tools`, `lint-knowledge` and the gate test install from the new path. Same binary name, same `Standard()` rules, same verdict on this bundle: `check -Werror` is silent before and after. The old module's tags stay resolvable on the proxy, so nothing pinned to them breaks.
- **Update**: the checker pin moves to `okfrules` v0.2.1, where `NoIntraBundleWikilinks` joins `Standard()`. It was `-strict`-only while one fleet bundle still carried bare wikilinks; that conversion finished and all ten bundles measured zero, so the rule now runs in every pinned repo rather than only the two that build their own checker. `Strict()` adds `LogVerbs` alone.

The pin arm below grades the new pin, so all three move in one commit.

Each proved by breaking it. The leftover `continue-on-error` CI step that re-ran `make lint-knowledge` and discarded the answer is deleted; `lint-all` already runs it blocking.
- **Update**: `lint-knowledge` folds in `-Werror` and `lint-knowledge-strict` is deleted. The strict target ended in `|| true`, so the CI step that ran it reported nothing a build could act on; a broken link is a *warning*, which plain `okf check` also prints and exits 0 on. One blocking target now, reached from `lint-all`, the pre-commit hook and CI. All ten personal bundles were measured warning-free first, so this costs zero reds, and it was proved by adding a dangling link and watching `make lint-knowledge` exit 2.
